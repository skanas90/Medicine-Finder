# 💊 Medicine Finder

A web-based application that helps users locate nearby pharmacies that stock specific medicines. Built with **Flask**, **PostgreSQL**, **Bootstrap/Custom CSS**, and includes user authentication and pharmacy management.

---

## 📌 Features

- 🔍 Search for medicines by name and location
- 🏪 View pharmacies with available stock
- 🔐 User login and signup system
- 🗂️ Admin panel to add and manage pharmacies
- 📋 Search history logging
- 📱 Responsive and clean UI with custom design
- 🧠 Pharmacy data stored in a PostgreSQL database

---

## 🛠️ Tech Stack

| Layer         | Technology                          |
|---------------|--------------------------------------|
| Backend       | Python (Flask)                      |
| Database      | PostgreSQL + SQLAlchemy             |
| Frontend      | HTML, CSS, MDB UI Kit, Bootstrap    |
| ORM/Migration | Flask-Migrate + Alembic             |
